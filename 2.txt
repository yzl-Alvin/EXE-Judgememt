题目背景
xzt是一个刚刚开始学校OI的蒟蒻，现在在做B2002HelloWorld出现了问题，请你帮帮他吧！

题目描述
给定一段代码，如果有错误，输出错误，否则输出"Hello,World!"。

输入格式
输入一段c++代码，以EOF结尾

输出格式
如果有错误，输出相应的错误（具体见样例），否则输出"Hello,World!"

输入输出样例
输入 #1复制

#include<bitss/stdc++.h>
using namespace std;
int mian(){
	cout<<"hello,world"
	return 0;
}
输出 #1复制

.h: No such file or directory
输入 #2复制

#include<bits/stdc++.h>
using namespace std;
int mian(){
	cout<<"hello,world"
	return 0;
}
输出 #2复制

expected';'before...
输入 #3复制

#include<bits/stdc++.h>
using namespace std;
int mian(){
	cout<<"hello,world";
	return 0;
}
输出 #3复制

collect2.exe	 ld returned 1 exit status
输入 #4复制

#include<bits/stdc++.h>
//using namespace std;
int main(){
	cout<<"hello,world";
	return 0;
}
输出 #4复制

'cout' was not declared in this scope
输入 #5复制

#include<bits/stdc++.h>
using namespace std;
int main(){
	cout<<"hello,world";
	return 0;
}
输出 #5复制

Hello,World!
说明/提示
所有可能出现的错误:

expected';'before...
'cout' was not declared in this scope
.h: No such file or directory
collect2.exe ld returned 1 exit status
